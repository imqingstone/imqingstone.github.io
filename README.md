# 青石驛

青石旅人的入口網站，串連拾穗、一念、觀易、紫垣、四時五個網站。

GitHub Pages 使用 main 分支的 `/docs` 目錄，網址為 https://imqingstone.github.io/ 。

## 檔案
- `docs/index.html`、`docs/style.css`：頁面。電腦顯示橫幅主視覺，手機顯示直幅主視覺。
- `docs/img/hero-wide.jpg`、`docs/img/hero-tall.jpg`：主視覺插畫。
- `docs/img/og.jpg`：在社群貼上網址時的分享縮圖（1200×630）。
- `docs/img/*.png`：五個網站的圖示。
