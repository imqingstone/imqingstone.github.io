六條小徑

走得久了，總想找個地方坐一會兒。青石驛是旅人的驛站，也是我替自己、替路上相遇的人，留下的六扇門。

拾穗，是在田埂上彎腰，拾起一句剛好的話；一念，是一念起時，輕搖籤筒，聽一支籤說話；觀易，是三枚銅錢六次起落，在變化裡看見自己；紫垣，是抬頭望見紫微垣的星，命盤是另一片夜空；四時，是春生夏長、秋收冬藏，八個字記下出生那一刻的時序；月杯，是兩彎新月輕輕落下，一平一凸，聽神明輕聲應答。

它們都不是預言，只是一面鏡子。願你在這裡歇歇腳，看清自己的心，再繼續上路。

選一條小徑

  • 拾穗解答之書 心裡有問題時，靜下來翻一頁。三百三十三句話，給此刻一個回答。
  • 一念六十四籤 搖一搖籤筒，求一支原創籤詩，附白話解籤，陪你看見下一步。
  • 觀易六十四卦 銅錢起卦，依你的問題解讀本卦與變卦；也有卦象圖鑑與入門學堂。
  • 紫垣紫微斗數排盤 排出紫微命盤，看星曜、四化、大限流年，以及一段白話總結。
  • 四時八字排盤 排出四柱八字，看日主、十神、五行、大運流年，以及一段白話總結。
  • 月杯擲筊 心裡默念一個問題，擲一次筊，或連擲三次求三聖筊，附白話說明。

每個網站都不用登入，也不收集個人資料；生日只保存在你自己的手機或電腦裡。

驛站後院

走累了，也可以在後院坐下，玩一局。

  • 靈蘭王國經營小品 陛下，該睡了。帶著四位大臣，讓王國平安度過春夏秋冬。
  • 日晷十二時辰小品 替旅人排一天。把行程排進十二時辰，每天一題，收集二十四節氣。
